This release turns Quisat into a children’s ministry workspace, organised the same way as Kids Clinics: one Kids Church menu on the web, with clear tabs instead of scattered school links. Parents and teachers use the Quisat app for check-in, pickup, photos, prayer, and this week’s lesson.

1. What we have delivered

Web — Kids Church dashboard

Staff sign in at the Quisat admin portal. Churches see a single Kids Church item in the sidebar (next to Kids Clinics). It opens a dashboard with stats and tabs:

Parent app

  • Home shows this week’s verse, prayer focus, this week’s lesson, pastor’s devotion, and today’s pickup QR
  • Check-in / pickup codes for Sunday drop-off
  • Quisat Moments — view, like, comment (comments visible to teachers only), download HD
  • Prayer box — submit a request (optional anonymous)
  • Lessons & faith — recap, memory verse, family challenge, home resources
  • Care reports — incident updates from staff
  • Events and Fees as before
  • Birthday push with a blessing verse (sent automatically at 07:00)

Staff / teacher app

  • Kids check-in and checkout (checkout requires the 4-digit pickup code)
  • Medical / allergy alerts on the child’s card at check-in
  • Create Moments albums (daily, event, or official class photo), tag children, publish to that group’s parents
  • Publish lessons and devotionals
  • Log care / incident reports (parent is notified immediately)
  • Update prayer request status and add a praise report

3. Before you test — enable the church

  1. Sign in to the Quisat admin as a super admin.
  2. Open the church business and enable the features Kids Church and Quisat Moments.
  3. On the live server, also run the latest database update (your technical contact will run php artisan migrate).
  4. Staff and parents need the latest Quisat app build for Lessons, Care reports, Moments tagging, and pickup QR.
Web address: https://app.quisat.com
Kids Church page: after login, sidebar → Kids Church (or go to /kids-church).

4. How to test — church staff on the web

A. Dashboard

  1. Log in as church staff. Confirm the sidebar shows Kids Church (school-only items such as Terms and Exams should be hidden for a church-only tenant).
  2. Open Kids Church. Confirm the hero stats (children, groups, checked in today, open pickup codes).
  3. Open the Overview tab. Confirm birthdays, medical alerts, and active lesson if data exists.

B. Groups and children

  1. Tab Groups → add Nursery / Kids / Teens.
  2. Tab Children → Add child, assign a group, fill Allergies and Medical notes.
  3. Tab Parents → Add parent, or Link by Quisat code using the code from the parent’s Profile in the app.
  4. Confirm Cancel / Save on a child form returns you to Kids Church, not a school students page.

C. Sunday check-in

  1. On the app (staff or parent), check a child in.
  2. On the web, open Check-in. Confirm today’s pickup code appears and attendance is Present.
  3. On the app, try checkout without the code — it should fail. Enter the correct 4-digit code — the child is released.

D. Lessons, prayer, memory wall

  1. Lessons → add a Weekly Bible lesson with object lesson, crafts, memory verse, and family challenge. Set status to Published.
  2. Add a Pastor devotion and a Home resource.
  3. Memory Wall → add this week’s verse and a prayer focus.
  4. Prayer → after a parent submits a request, change status to Being prayed for, then Answered, and add a praise report.

E. Incidents, volunteers, giving

  1. Incidents → log a health or behavioural note. Confirm the parent gets an in-app notification.
  2. Volunteers → add a teacher/helper, set background check to Cleared, enter hours.
  3. Fees / Giving → create a fee. Confirm it appears under Fees in the parent app.

F. Quisat Moments (web)

  1. Tab Moments → Create album, choose Daily / Event / Official class photo, pick a group, upload photos, publish.
  2. Only parents of that group should see the album in the app.

5. How to test — parent app

  1. Log in as a parent linked to the church (or link with the Quisat code).
  2. Home should show verse, prayer focus, this week’s lesson, and (after check-in) today’s pickup QR and 4-digit code.
  3. Open Check-in → check the child in. Confirm a pickup code appears and a notification arrives.
  4. Show the code (or QR) at pickup. Staff must enter that code to release the child.
  5. Open Moments → open the album → like, leave a comment for the teacher, Download HD. Confirm the privacy note (do not post outside Quisat).
  6. Open Prayer box → send a request (try anonymous as well).
  7. Open Lessons → confirm the published lesson, home resource, and devotion.
  8. If staff logged an incident, open Care reports and confirm the update.
  9. Open Events and Fees as usual.

6. How to test — teacher / staff app

  1. Log in as church staff.
  2. Open Kids Check-in. Confirm allergy / medical alerts on children who have notes.
  3. Check a child in. Confirm the pickup code. Check them out only after entering that code.
  4. Open Moments → New album → select group, album type, tag children, add photos, Publish. Confirm parents of that group get a push (“New Photos…” / “Your child was tagged”).
  5. Open Lessons → publish this Sunday’s material. Confirm parents are notified.
  6. Open Care reports → log an incident. Confirm the parent is notified.
  7. Open Prayer box → mark Praying, then Answered, and type a praise report.

7. Suggested demo script (10 minutes)

  1. Web: walk the Kids Church dashboard tabs (30 seconds each).
  2. Add a child with a peanut allergy → staff app check-in → show the medical warning.
  3. Parent app: show the pickup QR → staff checkout with the wrong code (fail) then the right code (success).
  4. Publish a lesson on the web → open it on the parent home.
  5. Upload a Moments album for Nursery → open it on a Nursery parent phone (and confirm a Teens parent cannot see it).
  6. Parent sends a prayer → staff marks Answered with a praise report.

8. Support notes

  • A tenant that is both a school and a church keeps school menus and Kids Church.
  • A church-only tenant should only see Kids Church (plus shared tools such as Chat, Staff, and Financials).
  • Pickup codes expire at the end of the day and can only be used once at checkout.
  • Moments albums are private to the group. They are not posted to Facebook or WhatsApp from Quisat.
